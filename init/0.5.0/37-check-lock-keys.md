## Applies when

The machine has lock keys ({{ref:lock-keys}}).

## Check

The shared check `locks` (Kairo#124): pressing each lock key turns it on in `locks()`, and a state saved with it on loads with it on. The check is written once, in the shared PC boot test ({{ref:boot-test}}); this ticket writes no test of its own. It gives {{app}}'s entries in `core/test/boot-tests.json` and makes them pass:

- Each lock key the machine has, with its key code and its bit in `locks()`.

## Passes when

- {{app}}'s entries pass, and breaking {{app}}'s side of what the check looks at fails them.
