# Licensing

The license for the first-party Kairo frontend source is pending review. This private repository currently grants no public reuse license.

The bundled Spleen 8x16 font is BSD-2-Clause. Its source and full notice are in `third_party/spleen/`. The generated 1,520-byte `frontend/src/main/assets/ui/spleen-8x16-ascii.bin` derives from that snapshot. Each consuming app must include the Spleen notice in its distributed license information.

Before distributing KairoDos with DOSBox Pure, choose GPL-compatible terms for the shared frontend code in that app and audit the exact combined artifact.
