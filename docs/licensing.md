# Licensing

Three bundled RetroArch presets are individually reviewed in [the pinned shader snapshot](../third_party/slang-shaders/README.md). Sharp Bilinear and Sharp Bilinear + Scanlines state public-domain terms. CRT EasyMode states GPL without a version; this build chooses GPLv3 under the GPL's no-version clause. Their source files retain the notices, and About -> Licenses identifies each preset and its terms. The upstream shader collection has no collection-wide license that applies to every file; do not infer redistribution permission for other presets from this selection.

The first-party Kairo frontend is GPL-2.0-or-later; see [COPYING](../COPYING). Kairo98 and KairoDos pin this source and provide corresponding source for their combined builds.

The Spleen 8x16 font is BSD-2-Clause. Its source and full notice are in `third_party/spleen/`; the generated `frontend/src/main/assets/ui/spleen-8x16-ascii.bin` derives from it.

The Gradle wrapper is Apache-2.0 build tooling, not app runtime code. Its license and notices are in `third_party/gradle-wrapper/LICENSE`. The shared repository contains no emulator engine, game, operating system, BIOS, ROM, catalog artwork, or signing material. `catalog/dos/online-v1.zip` is a public feed of hash identities, game titles, factual tags, launch settings, artwork paths, and controller profiles. The export removes eXoDOS/LaunchBox descriptions and contains no artwork. Third-party core and bundled catalog obligations belong to each product's combined build; see their licensing documents.

The frontend links AndroidX profileinstaller 1.4.1 and its Apache-2.0 runtime dependencies (startup-runtime, tracing, concurrent-futures, annotation, Guava listenablefuture) to install the baseline profile on sideloaded APKs. `frontend/src/main/assets/ANDROIDX_NOTICES.txt` lists them with the Apache-2.0 text, and both apps append it to About → Licenses.

The frontend links Apache Commons Compress 1.27.1 (Apache-2.0) and XZ for Java 1.10 (0BSD) for `DiskImageLibrary`'s 7z archives.

About → Licenses shows the app's own `THIRD_PARTY_NOTICES.txt` (its emulator and the libraries it links), then the notices every app carries through the frontend (`AboutDocuments.FRONTEND_NOTICES`): `FRONTEND_NOTICES.txt` (Commons Compress, XZ for Java and Spleen), `NDK_NOTICES.txt` (the LLVM notice of the NDK that builds the app's native code and statically links its C++ runtime, copied from that NDK at build time), `SLANG_RUNTIME_NOTICES.txt` (only in an app built with the shader runtime) and `ANDROIDX_NOTICES.txt`. An app lists none of these in its own notices. `tools/audit_android_release.py` checks a release carries all of them, and the shader runtime's notices exactly when it carries the runtime.

Librashader 0.11.0 is `MPL-2.0 OR GPL-3.0-only`; both products use its GPL-3.0-only option, so their combined shader-enabled builds are distributed under GPLv3 terms using first-party "or later" permission. Its full source and both upstream license texts are in `third_party/librashader/`. The Android OpenGL build has 129 pinned external Rust source archives in `third_party/cargo-crates/`. Their package names and SPDX license expressions, including build dependencies, are in `frontend/src/shaders/assets/SLANG_RUNTIME_NOTICES.txt`, which both apps append to About → Licenses. That notice also includes the GPL-3.0 and MPL-2.0 texts. Review the exact combined binary, transitively embedded native code, per-crate notices, and corresponding source before describing a release as audited.

An app whose emulator cannot be combined with GPL-3.0-only or Apache-2.0 code (for example a GPL-2.0-only core) sets `kairoShaders=false` in its `gradle.properties`. The frontend then packages no shader runtime, presets or shader notices, offers no shader settings (`BuildConfig.SHADERS`), and the app's native library is built without the shader presenter (`KAIRO_SHADERS=OFF`), so frames are always drawn in software.
